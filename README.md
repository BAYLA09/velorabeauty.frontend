# Velora Beauty — Frontend

UAE storefront with bundle pricing and clear card vs COD checkout.

## Pricing (AED)

| Bundle | Card | COD (+20 AED) |
|--------|------|---------------|
| 1      | 199  | 219           |
| 2      | 249  | 269           |
| 3      | 339  | 359           |

Logic lives in `src/lib/pricing.ts`.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
